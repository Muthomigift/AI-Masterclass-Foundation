## 6. Installation and Setup

To work with the projects locally, follow these steps.

### Prerequisites

Install the following:

- Python 3.x
- Git
- Visual Studio Code
- A GitHub account

### Clone the Repository

Open your terminal or PowerShell and run:

```bash
git clone https://github.com/Muthomigift/AI-Masterclass-Phase-1.git
```

Navigate into the project:

```bash
cd AI-Masterclass-Phase-1
```

Open the repository in VS Code:

```bash
code .
```

### Install Dependencies

Some projects require external Python packages.

Navigate into the relevant project folder and install its dependencies where a `requirements.txt` file is provided:

```bash
pip install -r requirements.txt
```

For projects using environment variables, create a `.env` file and configure the required API keys.

**Important:** Never upload API keys, passwords, `.env` files, or other sensitive information to GitHub.

## 7. Running the Projects

Each project has its own source files and execution requirements.

For a typical Python project:

```bash
python main.py
```

For a FastAPI application, where applicable:

```bash
uvicorn main:app --reload
```

Refer to the individual project files for specific execution instructions.
